一阶惯性 + 纯滞后（FOPDT）对象的阶跃响应

工业过程最常用的近似模型 G(s) = K·e−τs / (Ts+1)。K 决定最终稳定在哪，T 决定"跟得多快"，τ 决定"多久才开始动"。

判读：t=τ 处曲线才开始抬头（纯滞后），之后按指数逼近 K（增益）。到达 63.2% 终值还需 T 秒——这就是时间常数的定义。右下角的 τ/T 是判断"这个对象好不好控"的第一指标。

同一套 PID 参数，只改纯滞后

固定控制器参数与对象增益、时间常数，只把纯滞后 τ 从 0 逐步加大。滞后本身不改变稳态，却持续吃掉相位裕度——这是过程控制里"调不上去"最常见的原因。

四条曲线对应 τ₀、2τ₀、3τ₀、4τ₀。留意衰减比：滞后越大，振荡衰减越慢；当 τ 超过某个值后，同样参数会让系统彻底发散——此时唯一出路是降低增益或加补偿（见下一个实验）。

PID 参数整定：手调 vs Ziegler-Nichols

对象为 FOPDT。先看 Z-N 开环反应曲线法给出的参数，再自己拖滑块体会"为什么工程整定只是起点"。

Z-N 公式：Kp = 1.2T/(Kτ)、Ti = 2τ、Td = 0.5τ，设计目标是 4:1 衰减比。教科书常标称「约 25% 超调」，但对一阶滞后对象实测往往到 50% 以上——这正是工程上只把它当起点的原因：参数越激进，对模型误差和扰动的容忍度越低。切到「Z-N 收紧」看超调与调节时间怎么互换。

Smith 预估补偿：把滞后移出闭环

纯滞后 e−τs 不在闭环特征方程里，却让控制器"看不见"当前动作的效果。Smith 预估器用模型并行算一份"没有滞后的响应"，把滞后从反馈通道里抵掉。

蓝线为常规 PID，橙线为 Smith 预估。模型准确时差距惊人；把"模型失配"拖到 ±30%，橙线会迅速退化——Smith 的收益与模型精度强绑定，这也是它在工业现场不如串级普及的原因。

串级控制：用快回路守住慢回路

主对象慢（温度）、副对象快（流量/阀位）。当扰动进入副回路时，副控制器在它传到主变量之前就处理掉了——这是单回路做不到的。

灰线为单回路 PID（同样参数直接控制），蓝线为串级。扰动打在副回路时差距最大——单回路必须先等扰动穿过两个对象才在 y₁ 上看见，串级在副变量上就已经开始纠正了。切到"主回路扰动"再看，优势会明显缩小。

前馈-反馈复合控制：扰动可测就提前补偿

反馈是"错了再改"，前馈是"预判就改"。扰动 d 通过 Gd(s) 影响输出，若能测到 d，就串一个 Gff=−Gd/G 把它提前抵掉。

静态前馈只补稳态（u_ff = −K_d/K · d），扰动初期的动态偏差仍靠反馈收拾；动态前馈加上超前滞后环节 (T·s+1)/(T_d·s+1) 后，几乎能在扰动进入的同一时刻抵消掉它。注意前馈不改变闭环稳定性，它只是让反馈一开始就少干活。
试着把 Td 拖到接近主通道的 T（8 s）附近：静态与动态前馈会几乎重合——两条通道动态特性一致时，静态补偿就够了；差异越大，超前滞后的必要性越明显。
